# Nivash — Personal Portfolio Website
### Cybersecurity Enthusiast | Developer

A modern, responsive personal portfolio website engineered for **Nivash**, a B.E. Computer Science and Engineering (Cyber Security) undergraduate at Rathinam Technical Campus.

> **Tagline**: LEARN. BUILD. SECURE. INNOVATE.

---

## ⚡ Tech Stack & Architecture

- **Frontend Framework**: [React 18](https://react.dev/) + [Vite 6](https://vitejs.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/) with custom cybersecurity color palette
- **Icons**: [Lucide React](https://lucide.dev/) & [Skill Icons](https://skillicons.dev/)
- **Typography**: Space Grotesk (Headings), Inter (Body), JetBrains Mono (Code & Cyber Elements)
- **Interactions**: Interactive Modal Viewers, Typing Animation, Canvas Confetti

## 🚀 Local Development & Build

```bash
# Install dependencies
npm install

# Run Vite development server
npm run dev

# Build for production
npm run build

# Preview production build locally
npm run preview
```

## 🌐 Deployment to Vercel / Netlify

This project is pre-configured for instant zero-configuration deployment on **Vercel** or **Netlify**:
